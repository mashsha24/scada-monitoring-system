# SCADA-система мониторинга абсорбционной колонны

Веб-приложение для мониторинга технологического процесса абсорбции в реальном времени: сбор параметров процесса, журнал событий и журнал аварий с фильтрацией. Интерфейс спроектирован по принципам промышленных SCADA-систем диспетчерского контроля.

## Стек
- **Backend:** Python (Flask)
- **База данных:** SQLite
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)

## Функциональность
- Мониторинг параметров процесса в реальном времени: температура, давление, уровень, расход газа и жидкости на входе/выходе
- Цветовая индикация статусов по каждому параметру
- Журнал событий с фильтрацией по статусу и категории, поиском и статистикой
- Журнал аварий с поиском и статистикой по максимальным значениям параметров
- Автоматическое управление клапанами при выходе параметров за пределы нормы

## Структура базы данных
- показания датчиков (температура, давление, уровень, расход) со статусами по каждому параметру
- журнал действий системы/оператора (реакции на отклонения, сбросы, состояние клапанов)

## Файлы
- `app.py` — серверная часть, API endpoints
- `index.html` — главный экран мониторинга
- `log.html` — журнал событий
- `alarms.html` — журнал аварий
- `schema.sql` — структура базы данных
- `sample_data.sql` — примеры записей
